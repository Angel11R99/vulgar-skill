# Configuration and scripts

Configuration is request-local and optional: `language` (`en`/`es`), `region` (catalog filename), and `intensity` (`low`/`medium`/`high`). The generator accepts `--description`, `--language`, `--region`, `--intensity`, `--previous`, and `--catalog-dir`. Without Python, follow `SKILL.md` manually. Scripts use only Python's standard library. `generate_commit.py` selects a technical description and adds randomized catalog terms. `validate_catalog.py` checks JSON shape, uniqueness, required regional files, and prints counts. `validate_commit.py` checks Conventional Commit header format and required profanity count when given a catalog directory. They read files/arguments and print results only; they do not run Git commands, mutate repositories, configure Git, or install hooks.
